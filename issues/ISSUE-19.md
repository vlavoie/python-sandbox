**Type:** Feature  
**Status:** Added  
**Files:**
- `fpv-pov-finalize.md` — new skill
- `src/pasokon/finalize_workflow.py` — new panel
- `src/pasokon/project_state.py` — finalize_skill loaded
- `src/pasokon/gradio_app.py` — new tab + OUTPUTS_PROJECT wiring

## What was added

A new **Finalize** tab (🏁) for running a final lighting/color quality pass on a finished image without any structural changes. Replaces the failed pattern of using Phase 2 with no green zones for this use case.

**UI:** Source image upload + optional notes field + "✨ Finalize Image" button + output gallery. No prompt tab, no review loop. The prompt is auto-generated from `fpv-pov-finalize.md`.

**Generation flow:**
1. User uploads the finished image as the source
2. `_do_finalize` calls the chat API with the finalize skill + scene description from `fpv_panel.phase1_scene_description`
3. The LLM writes a short (50–80 word) finalization prompt: base preservation clause + lighting/color improvements + spatial lock
4. The image is generated with IMAGE_0 = character reference, IMAGE_1 = source image
5. Result shown in gallery; retry by clicking again

## Key invariants

- `fpv-pov-finalize.md` is completely isolated from `fpv-pov-image.md` and `fpv-pov-review.md` — no cross-contamination
- IMAGE_0 = `fpv_panel.reference_image_path`, IMAGE_1 = `source_image_path` (same convention as Phase 2)
- Prompts generated by the finalize skill must NEVER mention green zones, structural changes, or element additions
- `FinalizeWorkflowPanel` extends `WorkflowPanel` to reuse `generate_images_batch` and `_save_images_permanently`; `do_generate_prompt`, `build_review_context` are stubs (not called)
- `get_ui_outputs()` returns only `[output_gallery, _work_item_label]` — no model dropdowns (uses project-level model)
- Output path: `finalize-outputs/work-item-N/<timestamp>_iteration-M/image_1.png`

## Why a separate workflow, not Phase 2

Phase 2 is designed for green-zone surgical additions. Using it for lighting-only passes with no zones causes the model to treat the scene description as a creative brief and regenerate the image. The finalize workflow has a skill that explicitly forbids structural changes and produces consistently minimal prompts.
